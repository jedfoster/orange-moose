# To-do list interview exercise

A to-do list coding exercise, used for interviews in 2021, in three parts:

| Directory | What it is | Formerly |
|---|---|---|
| [`frontend/`](./frontend) | React exercise, as handed to candidates | `orange-moose` |
| [`frontend-solution/`](./frontend-solution) | Earlier version of the React exercise, with a worked solution | `rude-elk` |
| [`backend/`](./backend) | Express API exercise, with failing tests to make pass | `brave-lobster` |

Each directory keeps its full commit history (`git log -- backend/`).

## Candidate submissions

Each candidate worked in a CodeSandbox, which pushed their work to a `csb-*` branch. Those branches use the original root-level layout, from before the exercises moved into subdirectories. The PR for each branch is titled with the candidate's initials.
